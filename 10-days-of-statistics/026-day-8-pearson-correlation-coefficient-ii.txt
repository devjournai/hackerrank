PROBLEM:
----------------------------------
The regression line of y on x is:

3x + 4y + 8 = 0

The regression line of x on y is:

4x + 3y + 7 = 0

Find the value of the Pearson correlation coefficient (r).

STEP 1: REGRESSION LINE OF y ON x
----------------------------------
Given:

3x + 4y + 8 = 0

Rewrite in slope form:

4y = −3x − 8  
y = −(3/4)x − 2

So regression coefficient:

b_yx = −3/4

STEP 2: REGRESSION LINE OF x ON y
----------------------------------
Given:

4x + 3y + 7 = 0

Rewrite in slope form:

4x = −3y − 7  
x = −(3/4)y − 7/4

So regression coefficient:

b_xy = −3/4

STEP 3: USE CORRELATION FORMULA
----------------------------------
Formula:

r = ± √(b_yx · b_xy)

Substitute values:

r = ± √[ (−3/4)(−3/4) ]

r = ± √(9/16)

r = ± 3/4

STEP 4: DETERMINE THE SIGN
----------------------------------
Both regression slopes are negative, so r must be negative.

Therefore:

r = −3/4

FINAL ANSWER:
----------------------------------
Probability = −3/4
